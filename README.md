# GoLive LAN — instaladores

Compartilhe a tela em 1080p60 e jogue na Mesa com os amigos, direto de PC
pra PC pela sua LAN virtual (Radmin VPN ou Tailscale). Grátis, para Windows.

**Baixe pelo site oficial** ou pela última versão em
[Releases](https://github.com/NickB0ss/golive-releases/releases/latest)
(`GoLive-LAN-Setup-<versão>.exe`).

Este repositório guarda só os instaladores e os arquivos que o app usa para
se atualizar sozinho (`latest.yml` e `.blockmap`). O código-fonte não é
público.

O uso do app é regido pelo [Termo de Licença de Uso (EULA)](EULA.md).
Redistribuir o instalador fora dos canais oficiais não é permitido.
